# Contributing

HossRide is an authored work by Hossein Tabasi (2026).

This repository holds the design specification, not an open feature list.
The fourteen sections in `docs/master-prompt.html` are the source of truth.

## What belongs here

Issues that report errata in the specification: a contradiction between
sections, an ambiguous directive, a broken local HTML page, or a licence
or citation mistake.

## What does not belong here

Feature requests that violate the five standing constraints (section 14).
Pull requests that add collectibles, a day cycle, a named vehicle roster
invented without the author, binaries, keystores, or engine project files
that this tree does not claim to contain.

## How to report errata

Open an issue. Cite the section number (01 to 14). Quote the sentence
that is wrong or unclear. Propose a replacement sentence in the same
register as the specification.

Do not send unsigned Android packages. Do not send keystores.
